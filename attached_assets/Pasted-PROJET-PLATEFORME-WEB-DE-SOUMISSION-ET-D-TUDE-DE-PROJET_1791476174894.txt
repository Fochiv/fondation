PROJET : PLATEFORME WEB DE SOUMISSION ET D’ÉTUDE DE PROJETS
1. CONTEXTE DU PROJET
Je souhaite développer une plateforme web professionnelle (FONDATION DANGOTE) permettant à des entrepreneurs, porteurs de projets, petites entreprises et particuliers de soumettre un projet dans le cadre d’un programme d’accompagnement ou de financement.
La plateforme doit permettre :
•	de présenter clairement le programme ;
•	d’expliquer les critères d’éligibilité ;
•	de permettre à un candidat de créer une candidature ;
•	de collecter toutes les informations nécessaires sur le candidat ;
•	de collecter toutes les informations nécessaires sur son projet ;
•	de collecter les informations financières du projet ;
•	d'attribuer automatiquement un numéro unique à chaque dossier ;
•	d’enregistrer toutes les données dans une base MySQL ;
•	de rediriger le candidat vers WhatsApp après la soumission afin qu’il puisse obtenir de l’assistance ou poursuivre les échanges ;
•	de permettre au candidat de suivre l’état de sa candidature ;
•	de fournir un espace d’administration complet permettant de gérer les candidatures, les candidats, les projets, les témoignages et les statistiques.
IMPORTANT :
Ne jamais promettre automatiquement qu’un candidat recevra un financement.
Utiliser une formulation professionnelle telle que :
« Soumettre votre projet »
« Votre candidature sera étudiée selon les critères du programme »
et non :
« Obtenez automatiquement votre financement ».
Le site doit être crédible, moderne, professionnel, rassurant.

20. WHATSAPP
Créer un bouton WhatsApp configurable depuis l'administration.
Le numéro WhatsApp ne doit jamais être codé en dur dans plusieurs fichiers.
Stocker le numéro dans la table settings.
Créer automatiquement un message :
« Bonjour, je viens de soumettre une candidature au programme. Mon numéro de dossier est DG-2026-000001. Je souhaite obtenir des informations concernant la suite de ma candidature. »
Encoder correctement le message dans l'URL WhatsApp.
IMPORTANT :
WhatsApp doit être présenté comme un moyen de communication ou d'assistance et non comme une preuve automatique d'obtention du financement.
